# Notes

![My notes page](/docs/assets/notes.png)

## Create a note

1. Open **My notes**.
2. Select **New note**.
3. Enter a title and content.
4. Select **Save**.

## Edit a note

Select **Edit** on a note card. The dialog opens with the current title and content. Save your changes or cancel without saving.

## Delete a note

Select **Delete** and confirm. The note is removed permanently for the assignment scope.

## Pagination

The list shows 10 notes per page by default. Use **Previous** and **Next**, or change **Rows per page** to 20 or 50.

## Ownership

Regular users only see their own notes. Admins use **All notes** to read every user's notes, but editing and deleting remain owner-only.
