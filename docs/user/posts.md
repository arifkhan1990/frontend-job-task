# Posts

![Public posts page](/docs/assets/posts.png)

Posts are public. Anyone can open `/users/<id>/posts` without logging in.

## Publish a post

1. Open **My posts** from the sidebar.
2. Select **New post**.
3. Add a title and content.
4. Select **Publish post**.

Posts are sorted newest first and paginated. There is no edit or delete control for posts in this assignment.
