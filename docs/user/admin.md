# Admin views

Admins get three additional views in the sidebar.

## Users

![Users page](/docs/assets/users.png)

- Search the current page.
- Toggle columns to reduce the table.
- Select rows and use **Delete selected** for bulk removal.
- Create users with the **Add user** dialog.
- Edit a user's name, email, role or interests.
- **Posts** opens that user's public profile.

You cannot delete your own account or change your own role. The last admin is also protected.

## All notes

![All notes page](/docs/assets/all-notes.png)

A read-only table across every user. Filter by owner, search the current page, sort columns, and change page size.

## Users by interest

![Interests page](/docs/assets/interests.png)

The page uses one aggregation pipeline to group users by interest. It shows a distribution chart and one card per interest. Use the filter to narrow the view to a single interest.
